# Hits FM 93.5 – site

Novo site da rádio Hits FM 93.5, Palmas – Tocantins.

## Rodando localmente

```bash
npm install
npm run dev
```

Abra http://localhost:3000. A página `/style-guide` mostra todos os componentes base.

## Scripts

- `npm run dev` – servidor de desenvolvimento
- `npm run build` – build de produção
- `npm run lint` / `npm run typecheck` / `npm run format`

Setup do Supabase, deploy na Vercel e guia do painel chegam nas próximas fases.
